# Glossary

Short meanings of the terms used in the FreshFlow docs.

| Term | Meaning |
|---|---|
| API | A way for one program to ask another program to do something. FreshFlow uses the Claude API to write, check and translate content |
| API key | A secret code that proves you are allowed to use an API. Never share it or commit it to GitHub |
| Writer | The AI step that drafts the content using the brand guide |
| Checker | The AI step that tests a draft against the 10 compliance rules |
| Translator | The AI step that translates approved content into Telugu using a glossary |
| System prompt | Standing instructions sent with every request: the role, the brand guide and the rules |
| Token | A small piece of text. One token is about three-quarters of a word |
| JSON | A simple text format for data, used to pass results between workflow steps |
| n8n | A tool that connects steps into one automated workflow |
| Workflow | A chain of steps that runs in order, from the form to the Notion table |
| Compliance rule | A written rule that content must follow before a person can publish it |
| Needs Human Review | A status that means the checker is not sure, so a person decides |
| Prompt library | A Google Sheet that keeps every version of a prompt, with notes on what changed |
